Power BI - Sales Target

💡 Introduction

This Power BI project visualizes company sales performance against targets to support strategic monitoring and decision-making. It incorporates key metrics such as Current Achieved, Last Achieved, Current Backlog, Booking, Quota, Achieved %, Cumulative Achieved %, Growth %, Cumulative YOY %, and B/B Ratio —each chosen to capture sales progress, year-over-year growth, demand versus fulfillment, and overall target attainment.

Achievement and growth metrics help evaluate short- and long-term performance, while operational ratios like the B/B Ratio reveal the balance between incoming orders and fulfilled sales, signaling future pipeline strength.

On the other hand, filters for Year, Salesperson, Customer, Region, and Country allow users to analyze performance across different time periods, individual contributions, key accounts, and market regions—supporting more targeted sales and resource strategies.


🗝 Keywords: Data Analysis, Data Visualization, Power BI

📊 Dashboard Showcase

The report includes three pages:
• Sales Target Overview: Trend charts and gauges display achievement rates, growth trends, and order ratios, with a detailed KPI table for reference.
• Sales Breakdown: A sunburst chart and matrix visualize the proportional contribution of each region, customer, and salesperson.
• Cumulative Sales Achievement: Dual bar charts compare quotas to actual performance, complemented by a color-coded table highlighting underperformance.



🔨 Data Modeling

A. Data Modeling Process

1. Data Sources:
  • ERP (Order Master,Product Data...)
  • Excel (Manually maintained customer attributes)
2. Clean the data:
  • Standardize formats
  • Remove duplicates
  • Unify columns (e.g., date formats)
3. Create dimension and fact table structures:
  • Fact Tables
  • Dimension Tables
4. Establish relationships:
  • Single-directional
  • Star Schema
  • Customer, Product, and Sales connected via keys
5. Create DAX measures:
  • Total Sales
  • Year-over-Year (YOY)...

B. Case Study

1. Fact Tables

i. 受訂明細 (Order Details)

  • Contains order-level transactional data: order number, order date, product, customer, employee, amount, tax, etc.
  • Linked to 年度目標, 預計出貨, and 員工/客戶 Bridge.

ii. 銷售明細 (Sales Details)

  • Contains shipping/sales data: shipment date, shipped quantity, sales amounts, customer info, product info, etc.
  • Used to calculate measures like “Current Year Sales” and “Last Year Sales”.

iii. 預計出貨 (Planned Shipment)

  • Contains planned shipment information: delivery date, product, customer, employee, and amounts.
  • Connects to Calendar for date-based calculations and other dimensions for analysis.

2. Dimension Tables

i. 員工 (Employee)

  • Employee master data with unique employee IDs (GEN01).
  • Connected via 員工/客戶 Bridge to bridge transactional tables.

ii. 客戶 (Customer)

  • Customer master data including ID, name, region, etc.
  • Also connected via 員工/客戶 Bridge.

iii. 料號 (Product)

  • Product master data: product name, specifications.

iv. Calendar

  • Standard date table with columns: Date, Month Number, etc.
  • Used for time intelligence (e.g., yearly, monthly aggregation).

v. 年份 (Year)

  • Single-year table to support measures like “Current Year Sales”, “Last Year Sales”.
  • Uses "SELECTEDVALUE" in DAX for filtering measures.

3. Bridge Table

i. 員工/客戶 Bridge (Employee/Customer Bridge)

  • Handles many-to-many relationships between employees and customers.
  • Contains both Employee and Customer keys (GEN01, GEN02).

4. Supporting Table

i. 年度目標 (Annual Target)

  • Contains yearly targets per customer, region, and employee.
  • Links to Calendar for time analysis and measures like amount or revenue.
