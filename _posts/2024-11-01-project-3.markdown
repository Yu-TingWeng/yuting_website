    <h4>&#128161; Introduction &#128161;</h4>
    <p>This Power BI report demonstrates creating custom, interactive visuals by combining <b>DAX, HTML, SVG, and JavaScript.</b> Visuals include <b>state indicators</b> (green = good, yellow = on track, red = warning with blinking)<b>, liquid fill gauges, five-star ratings, linear and circular gauges, sparklines with intersection highlights, barcode charts by month, and boxplots.</b> Using DAX for data-driven calculations and HTML/JavaScript for rendering, each visual dynamically updates with the underlying dataset, allowing flexible styling and interactive effects. This project showcases how integrating scripting with Power BI enables highly customized, visually engaging dashboards beyond standard chart types.</p>
